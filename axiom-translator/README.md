# Axiom Translator

Расширение для Chrome / Edge / Brave / Opera / Яндекс Браузера, которое переводит тексты
пользователей на [axiom.trade](https://axiom.trade) на русский язык: коллауты (pump.fun callout),
посты, комментарии, чат — всё, что появляется на странице, в том числе всплывающие карточки над графиком.

## Как работает

- Следит за страницей (`MutationObserver`) и находит текст, похожий на сообщения людей.
- Пропускает цены, проценты, тикеры (`$PEPE`), адреса контрактов, ссылки, `@ники`, кнопки (`Follow`, `Block`…)
  и текст, который уже на кириллице.
- Переводит через Google Translate, результаты кэширует.
- Заменяет текст переводом. Рядом с каждым переведённым текстом появляется маленькая кнопка
  **«ориг.»** — нажмите, чтобы увидеть оригинал, повторное нажатие («перевод») вернёт перевод.
  Также оригинал показывается во всплывающей подсказке при наведении мышью.

## Установка

1. Скачайте архив `axiom-translator.zip` из корня репозитория и распакуйте его
   (или возьмите папку `axiom-translator`).
2. Откройте `chrome://extensions` (в Edge — `edge://extensions`, в Яндексе — `browser://extensions`).
3. Включите **Режим разработчика** (переключатель справа сверху).
4. Нажмите **Загрузить распакованное расширение** и выберите папку `axiom-translator`.
5. Откройте/обновите axiom.trade.

## Настройки (иконка расширения)

- **Переводить** — включить/выключить (при выключении возвращается оригинал).
- **Язык** — язык перевода (по умолчанию русский).
- **Мин. слов в тексте** — короткие строки короче этого числа слов не переводятся.
  По умолчанию 2: переводятся фразы, но не одиночные слова вроде названий токенов.
  Поставьте 1, если хотите переводить вообще всё.
- **Кнопка «ориг.» у текста** — показывать кнопку переключения оригинал/перевод.
- **Оригинал при наведении** — показывать исходный текст во всплывающей подсказке.
- **Очистить кэш переводов**.
